##QuickShop-info

 Live Demo:
 https://leilahajikhani2002.github.io/QuickShop/

🌐 Frontend Project
A responsive and modern frontend project built with HTML, CSS, Tailwind CSS, and swiper slider.

✨ Features
- 📱 Fully responsive design
- 🎨 Modern UI built with Tailwind CSS
- 🧩 Custom CSS styling
- 🖼️ Interactive sliders and carousels using swiper slider
- ⚡️ Fast and lightweight frontend
- 📐 Mobile-first design

🛠️ Technologies
- HTML5 — Page structure and semantic markup
- CSS3 — Custom styling
- Tailwind CSS — Utility-first CSS framework
- swiper slider — Responsive sliders and carousels
- NPM — Package management

📦 Installation
Clone the repository:
git clone https://github.com/LeilaHajikhani2002/QuickShop.git
Navigate to the project directory:
cd project-name
Install the dependencies:
npm install

🚀 Run the Project
Start Tailwind CSS in watch mode:
npm run build
Tailwind CSS will watch for changes in your files and automatically update the generated CSS.
Then open "index.html" in your browser.
